# Admin 个性化与触屏流量详情验收

## 功能与兼容边界

- 桌面保留排行 Tooltip；手机、平板与粗指针设备可点击排行项，使用现有详情工作区。手机为全屏，展示双周期上传、下载、总量、变化、占比和 UID/SID，并保留流量日志入口。
- Dashboard 的范围、排行类型、今天/昨天和 Top 数量同步 URL；日志返回后恢复条件和滚动位置。恢复等待数据及账号布局就绪，用户主动滚动时取消自动恢复。
- 13 个 Dashboard 模块支持独立显隐、上移/下移、运营/基础设施/精简预设。桌面与手机/平板分开设置，断点沿用现有 `1024px` 规则；恢复默认仅作用于当前编辑的设备布局。
- 表格保存列显隐与舒适/紧凑密度；命名视图包含筛选、列和密度，每表最多 10 个，同名保存为更新。应用视图回到第一页，保留页面不可编辑的上下文条件。
- “重置筛选”恢复页面原有筛选默认值（日志默认今天），保留列、密度、当前页大小及已保存视图。“恢复表格默认设置”同时恢复列、密度和分页默认值，但不删除命名视图。原有业务刷新/重置不会清掉 Admin 个人列和密度。
- 保留当前 Header、Sidebar、MotionProvider、Dashboard 卡片、统一 LogPage、移动卡片及 Dialog 规范。不改接口、客户端、Swagger、Schema、登录流程或后端。
- 表格持久化与新设置入口仅由 Admin Provider 启用；User Web 不增加设置入口或密度样式。

## 存储规则

- Dashboard：`ppanel.admin.dashboard.preferences.v2.<管理员 ID>`；表格：`ppanel.admin.table.v1.<管理员 ID>.<页面>.<表格标识>`，各段编码后保存至 localStorage。
- 切换账号立即隔离设置；账号尚未加载时不写持久化存储。旧版无账号隔离的全局 Dashboard 设置不自动导入，避免继承其他管理员的偏好；默认仍隐藏项目支持。
- 仅当前浏览器有效，不跨浏览器或设备同步。清除站点数据会删除设置。存储不可用时提示用户，修改仅保留在当前组件内存，刷新或离开后不保证保留。
- 密码、Token 等敏感筛选及不支持的复杂/超长值禁止保存，避免持久化凭据或静默删掉条件而扩大查询范围。
- 恢复表格默认设置保留命名视图；删除视图使用其单独的删除按钮。

## 验证限制

- 浏览器验证使用本地 Mock，不代表真实后端联调；本轮没有新增后端依赖。
- 六种尺寸各覆盖两种语言/主题组合，并非所有语言、主题、输入设备与接口状态的笛卡尔积。没有宣称真实低性能手机或真实后端验收完成。
